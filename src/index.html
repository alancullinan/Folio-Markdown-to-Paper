Safe HTML is supported. Scripts, embedded frames, and custom CSS are removed. Markdown dialects vary; MDX and executable extensions are not supported.

Local images: choose Images to attach matching files for relative image links, or insert new embedded images at the cursor. Images embedded as data URLs remain in saved Markdown. Remote images require a connection.

PDF: Export PDF opens the browser’s print dialog. Choose “Save as PDF”, match the selected paper size, use 100% scale, and turn off browser headers and footers. The app supplies margins and page numbers.

Shortcuts: Ctrl/Cmd+Z undo · Ctrl/Cmd+Shift+Z or Ctrl+Y redo · Ctrl/Cmd+S save · Ctrl/Cmd+O open · Ctrl/Cmd+B bold · Ctrl/Cmd+I italic · Ctrl/Cmd+P print. Drafts are stored in this browser when storage is available.

Make it your own.

Choose a heading font and table treatment. Changes appear in the preview and printed document.

Choose your body font from the Type menu in the toolbar. Source Serif 4, Source Sans 3, Lora, and IBM Plex Mono are bundled for consistent offline and PDF output. Style choices are saved in this browser draft; plain Markdown files contain content only.
